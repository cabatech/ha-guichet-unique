# HA - Guichet Unique

Dépôt d'add-ons Home Assistant.

| Add-on | Description |
| ------ | ----------- |
| [HA - Guichet Unique](guichet_unique/README.md) | Inscriptions périscolaire/cantine (espace-citoyens.net) vers un agenda Home Assistant (Google ou local) + entités cantine/périscolaire/coûts |

Ajouter ce dépôt dans HA : Paramètres → Modules complémentaires → Boutique → ⋮ →
**Dépôts** → `https://github.com/cabatech/ha-guichet-unique`.
