{% else %} {# --- Onglet Intégration --- #}
Principe

Vous pouvez brancher ce calendrier dans Google Agenda, Apple Calendar, Thunderbird ou DAVx5 (Android, mode lecture seule) en leur donnant l'URL d'un flux iCal authentifié. Un token dans l'URL sert d'authentification.

Important :

  • Le flux est en lecture seule (subscription iCal). Toute modification doit passer par le portail famille espace-citoyens.net.
  • L'URL publique est {{ public_base_url }} (modifiable via GUICHET_PUBLIC_URL dans .env).
  • Si un token fuite, révoquez-le depuis cette page : le flux correspondant cessera immédiatement d'être servi.

Branchement rapide
Google Agenda (web)
  1. Ouvrir Google Agenda (ou l'app mobile)
  2. Autres agendas (à droite) → + → À partir d'une URL
  3. Coller l'URL copiée ci-dessus (https://guichet.example.com/ical/<token>)
  4. Valider : la sync s'actualise toutes les ~12 h côté Google.
Apple Calendar (iOS / macOS)
  1. Réglages → Calendrier → Comptes → Ajouter un compte → Autre → Ajouter un compte CalDAV
  2. Type d'authentification : URL
  3. Adresse : l'URL complète copiée ci-dessus ; identifiant : au choix ; mot de passe : vide

Apple Calendar interprète l'iCal comme un calendrier en lecture seule abonné. C'est la même URL.

DAVx⁵ (Android, lecture seule)
  1. DAVx⁵ → Ajouter un compte → Connexion avec URL uniquement
  2. URL de base : l'URL copiée ci-dessus (sans `/` — DAVx⁵ re-routent CalDAV)
  3. Cocher Lire seulement (le service est en lecture seule)
